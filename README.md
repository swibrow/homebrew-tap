# homebrew-tap

Homebrew tap for [swibrow](https://github.com/swibrow) CLI tools.

## Usage

```sh
brew tap swibrow/tap
```

## Available Packages

| Package | Type | Description | Version | Install |
|---------|------|-------------|---------|---------|
| [agent-ops](https://github.com/swibrow/agent-ops) | formula | TUI for monitoring and resuming Claude Code agent sessions in tmux | 0.4.0 | `brew install swibrow/tap/agent-ops` |
| [gha](https://github.com/swibrow/github-actions-tui) | cask | Terminal UI for GitHub Actions | 0.6.0 | `brew install --cask swibrow/tap/gha` |
| [how](https://github.com/swibrow/how) | cask | Smart terminal cheatsheet — ask a question, get a command | 2.1.0 | `brew install --cask swibrow/tap/how` |
